==========================================================
 opencode-webui 포트 / 환경설정 안내
==========================================================

이 폴더의 start_opencode_webui_exe.bat(.sh) 로 실행하면
.env 파일이 없을 경우 아래 기본값으로 자동 생성됩니다.

  PORT=5002
  HOST=0.0.0.0
  NODE_ENV=production

■ 포트 변경 방법
 1) 메모장으로 .env 열기
 2) PORT=5002 를 원하는 포트로 수정 (예: PORT=8080)
 3) 저장 후 서버 재시작 (스크립트 다시 실행 또는 프로세스 종료 후)
    - 접속 주소도 함께 바뀝니다: http://<호스트>:<포트>

■ 주요 키
  PORT                 웹 UI/백엔드 포트           (기본 5002)
  HOST                 바인딩 주소                  (기본 0.0.0.0 = 모든 NIC)
  OPENCODE_SERVER_PORT opencode 내부 서버 포트      (기본 5552, 충돌 시에만 변경)

■ 참고
 - 이미 서버가 실행 중이면 스크립트가 "already running" 으로 알려줍니다.
   포트를 바꿨다면 기존 프로세스 종료 후 다시 실행하세요.
 - .env 를 지우면 다음 실행 때 기본값으로 다시 생성됩니다.
 - 그 외 키(타임아웃·파일 크기 제한 등)는 저장소의 .env.example 참고.
